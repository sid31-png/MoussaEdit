# Moussa Mouatez — Portfolio

Personal portfolio site for Moussa Mouatez, Junior Video Editor. Built with Next.js (App Router), Tailwind CSS, and Framer Motion, configured for static export.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All copy is sourced from `src/lib/data.ts`, pulled directly from the CV — edit that file to update experience, skills, or contact details. Photo and résumé PDF live in `public/`.

## Build

```bash
npm run build
```

Produces a static export in `out/`, deployable to Vercel, Netlify, or any static host.
